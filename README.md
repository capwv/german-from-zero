# الإنجليزي من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم الإنجليزي من الصفر، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/english-from-zero/

## المحتوى

- **14 درس**
- **84 سؤال تفاعلي** بتصحيح فوري وشرح
- **56 تمرين** بحل نموذجي
- **معمل لغة** جوه المتصفح: ترتيب جمل مع نطق صوتي، تحديات جرامر، بطاقات مفردات

## الدروس

1. الحروف والنطق
2. التحيات و to be
3. النفي والسؤال
4. a و an و the والجمع
5. الأرقام والتاريخ والوقت
6. المضارع البسيط
7. المضارع المستمر
8. أسئلة Wh
9. حروف الجر
10. الماضي البسيط
11. المستقبل
12. can و must و should
13. محادثات يومية
14. المشروع الختامي

## التقنية

صفحة واحدة بدون build: HTML + CSS + JavaScript خام. التسجيل والتقدم والشهادة من نفس نظام باقي الأكاديميات.
